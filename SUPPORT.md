# PlexVariables Support

## Before Opening an Issue

Please check:

1. The project README.
2. PlexDocs.
3. The PlexVariables Wiki when the relevant page exists.
4. Whether the problem can still be reproduced on the version you are using.

## Bug Reports

A useful bug report includes:

- PlexVariables version
- Minecraft version
- Paper version
- Java version
- PlaceholderAPI version
- relevant configuration
- exact placeholder or variable definition involved
- steps to reproduce
- expected result
- actual result
- relevant console output

Remove passwords, tokens, credentials, private database information, and other secrets before posting logs or configuration.

## Feature Requests

Describe the problem or use case first.

Then explain the behavior you would like PlexVariables to support.

## Private or Sensitive Reports

For a security-sensitive report that should not be public, contact:

`devapplex@gmail.com`

Use a clear subject such as:

```text
PlexVariables Security Report
```
