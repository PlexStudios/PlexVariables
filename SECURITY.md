# Security Policy

Please do not disclose an exploitable PlexVariables security issue in a public issue before it can be reviewed.

For security-sensitive reports, contact:

`devapplex@gmail.com`

Suggested subject:

```text
PlexVariables Security Report
```

Include only the information required to reproduce and understand the problem.

Do not send production credentials, unrelated private data, access tokens, or database secrets.

Ordinary bugs that are not security-sensitive should use the public bug report form.
